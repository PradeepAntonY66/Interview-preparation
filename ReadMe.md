# Behavioral Interviews

### Prepare stories using the STAR format.

#### Sample Questions:

1. Tell me about yourself.
2. Tell me about a failure.
3. Describe a conflict.
4. Why this company?
5. Most difficult bug?
6. Biggest achievement?

# Interview Strategy

### For each coding problem:

1. Clarify the requirements.
2. Discuss a brute-force approach.
3. Analyze its complexity.
4. Improve it step by step.
5. Explain your optimized solution before coding.
6. Write clean, readable code.
7. Test with small examples and edge cases.
